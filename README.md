## Prerequisite
1.  Installed require python library:
  -  langchain-community
  -  llama_cpp_python
  -  langchain
  -  langgraph
2.  Prepare the LLM (with format .gguf)
  -  Models that were used in this project:
      -  <a href="https://huggingface.co/gsxrchris/gemma-3-4b-it-Q4_K_M-GGUF">Gemma 4B</a>
      -  <a href="https://huggingface.co/TheBloke/Mistral-7B-Instruct-v0.1-GGUF">Mistral 7B</a>

## Instruction
1.  To run the agentic AI run `python3 main.py`
2.  To add more tools please visit `tools.py`
